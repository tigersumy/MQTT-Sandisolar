# Інструкція для Hermes Agent: Отримання статусів інвертора та живлення

Цей документ є системною інструкцією для **Hermes Agent**. Він детально описує, як та звідки отримувати поточні дані про роботу гібридного інвертора SandiSolar Aohai, рівень заряду акумулятора та наявність міської мережі (220V) для формування точних відповідей користувачеві.

---

## 🔍 Джерела даних та методи збору інформації

Для отримання інформації про стан системи використовуйте один із трьох перерахованих методів. **Метод 1 є найшвидшим та найбільш рекомендованим.**

### 📥 Метод 1: Зчитування останнього запису JSON-логу (Найшвидший та найпростіший)
Демoн автоматизації записує поточний стан системи кожну хвилину у файл логу подій.

*   **Шлях до файлу логу**: `./logs/tuya_power_log.json` (або за шляхом, визначеним у змінній `LOG_DIR`)
*   **Формат**: JSON Lines (кожен рядок є самостійним JSON-об'єктом).
*   **Інструкція для Агента**: Зчитайте останній рядок цього файлу та розпарсіть його.

#### Приклад останнього рядка в лозі:
```json
{
  "timestamp": "2026-08-09T15:45:25.102394", 
  "event_type": "status_update", 
  "grid_voltage": 228.4, 
  "status_text": "СВІТЛО Є", 
  "inverter_status": "off", 
  "battery_soc": 95, 
  "action_taken": null
}
```

#### Інтерпретація полів:
*   `status_text`: Наявність міської мережі («СВІТЛО Є» або «СВІТЛА НЕМАЄ»).
*   `grid_voltage`: Точна напруга міської мережі в Вольтах (наприклад, `228.4` В).
*   `inverter_status`: Стан роботи інверторної частини (`running` — генерація 220V увімкнена, `off` — генерація вимкнена / режим очікування або байпас).
*   `battery_soc`: Рівень заряду акумулятора у відсотках (наприклад, `95`%).
*   `timestamp`: Час останнього зрізу даних (перевіряйте, щоб дані були актуальними).

### 📡 Метод 2: Пряме опитування локального MQTT-брокера
Оскільки всі дані транслюються через локальний брокер Aedes, Агент може отримати свіжі значення параметрів безпосередньо з топіків.

*   **Реквізити MQTT**:
    *   **Host**: `localhost` (порт `1883`)
    *   **Користувач**: `sandisolar_inv`
    *   **Пароль**: `sandisolar_pass`

*   **Команди для зчитування в терміналі (одноразове отримання)**:
    *   **Напруга міської мережі**:
        ```bash
        mosquitto_sub -h localhost -u sandisolar_inv -P sandisolar_pass -t "sandisolar-controller/sensor/grid_voltage/state" -C 1 -W 2
        ```
    *   **Рівень заряду АКБ (SOC)**:
        ```bash
        mosquitto_sub -h localhost -u sandisolar_inv -P sandisolar_pass -t "sandisolar-controller/sensor/battery_soc/state" -C 1 -W 2
        ```
    *   **Статус інвертора (Power Switch)**:
        ```bash
        mosquitto_sub -h localhost -u sandisolar_inv -P sandisolar_pass -t "sandisolar-controller/switch/power_switch/state" -C 1 -W 2
        ```

### 🌐 Метод 3: HTTP API запити до плати ESP32
Плата ESP32 (ESPHome) надає власний веб-інтерфейс з REST API у локальній мережі.

*   **IP-адреса плати**: `<ESP32_IP>` (наприклад, `http://192.168.1.219`)
*   **Запити для отримання стану**:
    *   Запит `GET http://<ESP32_IP>/sensor/grid_voltage` ➡️ повертає JSON зі станом напруги мережі.
    *   Запит `GET http://<ESP32_IP>/sensor/battery_soc` ➡️ повертає JSON зі станом заряду акумулятора.
    *   Запит `GET http://<ESP32_IP>/switch/power_switch` ➡️ повертає JSON зі станом перемикача генерації.
