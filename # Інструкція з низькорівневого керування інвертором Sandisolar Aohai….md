# Фінальна інструкція з керування інвертором Sandisolar Aohai через Modbus

Цей документ містить підтверджені практичними тестами параметри адресації для гібридного інвертора Sandisolar Aohai AO-6KSL-G3 у додатку HaiPower.

## 1. Головний секрет адресації (Логіка роздільних регістрів)
На відміну від загального опису в документації, у поточній прошивці інвертора керування живленням реалізовано через дві окремі імпульсні команди (тригери). Вони приймають значення **`1`** (`Int1`), але надсилаються на різні адреси.

---

## 2. Керування живленням інвертора (Старт / Стоп)

Для керування використовується тип регістрів **`HOLD`** (Holding Registers / Регістри зберігання).

### 🛑 Команда ВИМКНЕННЯ інвертора
* **Register address:** `0`
* **Value:** `1` (вводиться як чиста цифра після префікса `Int`)
* **Дія:** Натиснути кнопку **`Settings`**. Інвертор програмно вимикається.

### 🟢 Команда УВІМКНЕННЯ інвертора
* **Register address:** `1`
* **Value:** `1` (вводиться як чиста цифра після префікса `Int`)
* **Дія:** Натиснути кнопку **`Settings`**. Інвертор програмно вмикається.

> ⚠️ **Важливо про читання стану:** Обидва регістри є імпульсними командами швидкої дії. Вони не зберігають свій стан постійно. При спробі зчитати їх кнопкою `Read`, поле `Hex` може повертати `0000` або `0001` залежно від поточного внутрішнього циклу процесора, що є нормою.

---

## 3. Таблиця інших важливих параметрів (Holding Registers)
Для налаштування інших конфігурацій інвертора діє правило зміщення адреси в програмі на **+1** відносно заводського списку:

| Функція параметру | Заводський номер | Адреса в програмі | Робочий діапазон значень |
| :--- | :---: | :---: | :--- |
| **BaudrateSet** (Швидкість зв'язку RS485) | 4 | **5** | `0` — 9600 bps, `1` — 38400 bps |
| **ChargeRate** (Макс. потужність зарядки) | 137 | **138** | Від `0` до `100` (у відсотках `%`) |
| **AcCharge_En** (Зарядка від міської мережі) | 145 | **146** | `1` — Дозволено, `0` — Заборонено |
| **SourcePriority** (Головний пріоритет живлення) | 182 | **183** | Від `0` до `10` (вибір режиму роботи) |

---

## 4. Пам'ятка щодо роботи з інтерфейсом програми
1. **Режим HOLD:** Використовуйте лише тоді, коли потрібно змінити параметр або надіслати команду (кнопка `Settings`).
2. **Режим INPUT:** Використовуйте виключно для читання поточних датчиків (генерація сонця, напруга акумулятора, температура) кнопкою `Read`. Запис у цьому режимі заблоковано інвертором.
3. **Поле Value:** Префікс `Int` є статичною міткою типу даних. Вводити цифри команди (`1` або `0`) потрібно строго після або замість нього (залежно від версії утиліти), щоб уникнути помилок формату.
